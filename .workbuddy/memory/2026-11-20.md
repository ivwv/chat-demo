## 设置导入支持合并（commit fbce31b）

- 之前导入只能整体覆盖，新增「合并导入」选项，确认弹窗三选一：取消 / 合并导入 / 覆盖导入
- 合并规则：服务商按 id 合并（本地独有保留，同 id 用导入值更新字段，模型取并集）；自定义提示词同样按 id 合并
- 合并模式不覆盖界面偏好与当前模型（`activeKey` 保留本机，为空时才用导入值）
- `applySettingsBackup(backup, mode)`，默认 replace 保持原行为
- E2E：本地 A/C + 提示词 A/C，导入 A/B + 提示词 A/B → 合并后 A 更新、B 新增、C 保留、模型 A 为并集、locale/激活模型不变，8/8 通过
